# appie

Developed Organisational Timesheet MVP(TESSOLVE) to simplify timesheet submission and reduce manual follow-ups. It unifies Timesheet, Leave Tracker, Holiday Calendar, Announcements, and Smart Alerts in one app, enabling faster updates, timely reminders, and easy access to important organizational information.
